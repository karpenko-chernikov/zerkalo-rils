Рилс с круглым зеркалом
=======================

Из фотографий с круглым зеркалом собирается вертикальное видео 1080×1920.
На всех кадрах круг одного размера и в одном месте. Снимок не растягивается:
масштаб по ширине и высоте всегда одинаковый.

Основной набор — папка варианты/отбор: 40 кадров, один круг,
каждое фото само закрывает экран.


Куда что класть
---------------

фото/       снимки с айфона
музыка/     один трек
настройки.json   размер кадра, место и радиус круга, кусок трека
разметка/   сюда скрипт запишет, где на каждом фото лежит круг
варианты/отбор   основные кадры рилса, их можно смотреть по одной
готовое/    рилс.mp4 и ритм.txt со списком склеек


Первый запуск
-------------

Открой Терминал и выполни:

    cd ~/Projects/zerkalo-rils
    source .venv/bin/activate
    python рилс.py проверка
    python рилс.py разметить
    python рилс.py собрать


Как отметить круг
-----------------

На фото сразу лежит круг. Центр искать не нужно.

    середина круга    перетащить круг на зеркало
    край или ручки    изменить размер
    пустое место      нарисовать заново: протяни от одного края
                      зеркала до противоположного
    Enter             сохранить и перейти к следующему
    колёсико, − и =   размер
    стрелки           чуть подвинуть
    Backspace         вернуть круг в центр кадра
    Tab               пропустить сейчас
    3                 исключить фото из ролика
    Esc               выйти. Уже сохранённое останется на месте

Справа видно, как кадр встанет в рилс. Белое кольцо там — место,
куда должен лечь край зеркала. Подгони круг и только потом жми Enter.

Уже отмеченные фото при следующем запуске пропускаются.
Пройти всё заново: python рилс.py разметить --заново


Что остаётся постоянным
-----------------------

1. Пропорции фото. Нет отдельного масштаба по ширине и по высоте,
   поэтому лица и улица не становятся шире или уже.
2. Место круга. Центр зеркала всегда попадает в точку из настройки.json.
3. Размер круга. Радиус на всех кадрах равен «радиус» из настройки.json.

Эти три числа можно поменять в настройки.json и заново собрать ролик.
Кликать по фото ещё раз не нужно: в разметке записан круг на исходнике,
а в кадр он переносится заново.

Сейчас круг стоит чуть выше середины: центр (540, 900), радиус 280.
Середина кадра по высоте была бы 960. Чуть выше — чтобы низ рилса,
где в Инстаграме подписи и кнопки, не съедал зеркало.


Если вокруг зеркала мало кадра
------------------------------

Размер и место круга внутри одного варианта не меняются. Это строго.

Часть фото уже закрывает кадр 9:16, часть — нет. Размазывание края
выглядело плохо, поэтому есть три отдельных папки:

    python рилс.py варианты

варианты/крупный-круг
    Круг один и тот же у всех, но больше. Настолько, чтобы каждое
    фото само закрыло кадр. Дорисовки нет. Круг может вылезти
    за левый и правый край экрана — одинаково на всех снимках.
    Цвет с айфона переводится на экран, кадр чуть ярче и резче.

варианты/рамка
    Круг прежнего размера. Где фото кончается, лежит ровный тёмный
    фон. Это рамка, снимок там не продолжается.

варианты/дорисовка
    Круг прежнего размера. Пустые края дорисовывает нейросеть
    по тому, что видно на границе фото. Зеркало она не трогает.
    Первый запуск скачает модель. Если дыра очень большая,
    место стыка всё же можно заметить.

    python рилс.py ещё

варианты/резкий-круг
    Круг прежнего размера. Резким остаётся только само зеркало.
    Всё вокруг размыто.

варианты/отбор
    Круг один на всех, такого размера, чтобы кадр закрывали
    около сорока фото. Остальные в эту папку не попадают.
    Сами снимки из папки «фото» не удаляются.


Музыка и ритм
-------------

Склейка встаёт на удары. По умолчанию каждое фото держится один удар.
Если мелькает слишком быстро, в настройки.json поставь "ударов_на_фото": 2
или 4. Тогда снимок останется на два или четыре удара.

Длинный трек обрежь, иначе ролик получится на всю песню:

    "начало_секунды": 42.0,
    "конец_секунды": 57.0

Темп скрипт ищет сам и пишет его в терминал и в готовое/ритм.txt.
Если склейки попадают между ударами, а не в них, задай темп руками
(ударов в минуту) и сдвиг:

    "темп": 120,
    "сдвиг_секунд": 0.05

Сдвиг двигает всю сетку ударов. Положительное значение — позже.


Порядок кадров
--------------

Без порядок.txt фото идут по имени. Снимки с айфона обычно так и лежат
по времени: IMG_0001, IMG_0002 и дальше.

Свой порядок — файл фото/порядок.txt:

    IMG_1042.HEIC
    IMG_1100.JPEG
    # строки с решётки скрипт не читает

В ролик попадут только перечисленные файлы, сверху вниз.


Две команды сборки
------------------

Сначала только картинки, без видео. Их удобно пролистать в папке кадры/:

    python рилс.py собрать --только-кадры

Когда круг на всех кадрах стоит одинаково:

    python рилс.py собрать

Готовый файл: готовое/рилс.mp4
Он перезаписывается при следующей сборке.
